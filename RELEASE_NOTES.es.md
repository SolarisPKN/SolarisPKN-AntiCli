# SolarisPKN-AntiCli 0.1.0 — Primera versión preliminar

Solaris AntiCLI es un cliente experimental de escritorio, desarrollado con Avalonia y .NET, para administrar acciones de consola revisadas a través de SSH.

**Novedades:** selección de sistema operativo remoto, verificación SHA256 de huella SSH, almacenamiento DPAPI opcional e independiente de credenciales, múltiples pestañas/ventanas, clonación de autenticación, construcción visual de comandos, autocompletado y exploración de `--help` con borradores **no ejecutables**.

**Cliente disponible en esta vista previa:** Windows x64. Servidores remotos compatibles: Debian, Ubuntu, otras distribuciones Linux y Windows con SSH.

**Advertencia:** es una versión preliminar, no auditada ni recomendada para producción. Es necesario compilar y comprobar el commit publicado, verificar la identidad de los servidores por otro canal y explorar ayudas únicamente en máquinas de prueba autorizadas. No hay shell interactiva persistente ni ejecución automática de módulos o traducción detallada con IA.
